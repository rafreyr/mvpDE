# Engenharia de Dados: MVP

Este é um repositório para o MVP para a sprint de Engenharia de Dados da pós-graduação de Ciência de Dados & Analytics da PUC-Rio 2026.

O MVP foi desenvolvido utilizando pyspark e sql no Databricks para realizar uma análise da indústria internacional de produção de filmes.

Para mais detalhes, consulte o documento de projeto: [mvpDE[documentação].pdf ](https://github.com/rafreyr/mvpDE/blob/main/mvpDE%5Bdocumentac%CC%A7a%CC%83o%5D.pdf)

Também estão disponíveis os notebooks originais e suas saídas, além de imagens ilustrativas e diversos screenshots do processo.
